# Documentation

This directory contains the written procedure and analysis material for the lab.

- `LAB_WALKTHROUGH.md` — task-by-task instructions aligned with the Cisco lab.
- `ANALYSIS_WORKSHEET.md` — fill-in questions for the three handshake packets and reflection.
- `TCP_HANDSHAKE_NOTES.md` — short explanation of the packet exchange and fields to inspect.

Record actual results from your own CyberOps VM session. Do not treat sample values in the handout as your results.
