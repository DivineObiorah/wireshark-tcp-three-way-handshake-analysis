# Screenshots

Store genuine screenshots captured while completing this lab in the subfolders below.

## Subfolders

- `part-1-setup/` — VM, Mininet, H1/H4, server, Firefox, and capture setup.
- `part-2-wireshark/` — TCP filter and each of the three handshake packets.
- `part-3-tcpdump/` — manual-page `-r` lookup and tcpdump readout.
- `cleanup/` — Mininet shutdown and cleanup.

## Naming convention

Use the numbered filenames from the root `EVIDENCE_CHECKLIST.md`, for example:

- `01-cyberops-desktop.png`
- `07-wireshark-tcp-filter.png`
- `08-handshake-syn.png`
- `09-handshake-syn-ack.png`
- `10-handshake-ack.png`
- `12-tcpdump-read-three.png`

Keep names lowercase, descriptive, and numbered in task order. Use PNG where possible. One clear image per evidence point is preferred; avoid multiple near-identical screenshots.

## Screenshot standards

- Show enough of the application or terminal to establish context.
- Keep the relevant command, filter, packet details, or output readable.
- Do not alter packet values or manufacture terminal output.
- Do not show passwords or unrelated private information.
- If a task fails, capture the real error and explain it in your notes.
