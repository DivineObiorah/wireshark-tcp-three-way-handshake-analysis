# Scripts

This directory contains small, optional helper scripts written for this repository.

- `capture_tcpdump.sh` — runs the lab's tcpdump capture command on H1.
- `read_first_three_tcp_packets.sh` — reads the first three TCP packets from the saved PCAP.

These helpers are **not** supplied by Cisco and are not required by the lab. They wrap the commands documented in `COMMANDS.md`. Run them only inside the correct CyberOps/Mininet host terminal. The supplied topology and web-server scripts remain inside the CyberOps VM and are not copied here.
