# Captures

The lab creates `/home/analyst/capture.pcap` inside the CyberOps VM. If you intentionally export a copy for local analysis, place it here.

PCAP files are ignored by `.gitignore` by default because packet captures can contain sensitive network metadata or payloads. Review and sanitize any capture before changing the ignore rule or publishing it. A screenshot and written packet observations are usually sufficient for a public portfolio.
